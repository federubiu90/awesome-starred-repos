# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project, please do not open a public issue.

Please report it privately through the GitHub Security tab for this repository:

- Go to the repository on GitHub
- Open the Security tab
- Select "Report a vulnerability"

If private reporting is not available for this repository, contact the maintainer directly through GitHub and include a detailed description, reproduction steps, and impact assessment.

## Scope

This policy applies to all source code, configuration files, automation, dependencies, and secrets used by this project.

## Disclosure expectations

We aim to acknowledge valid reports within 5 business days and work toward a remediation timeline that is appropriate to the severity of the issue.

## Safe harbor

Security research that is conducted responsibly and in line with this policy is welcomed and encouraged.
